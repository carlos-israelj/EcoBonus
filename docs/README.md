## UI/UX Design

Based on the uploaded design (5 screens shown):

1. **Login Screen**: Passkey and Stellar wallet options
2. **Map View**: Interactive map showing mission locations with pins
3. **Mission Details**: Mission info, GPS verification, and evidence upload
4. **Claim Submission**: Before/after photos with GPS tracking
5. **Rewards & Leaderboard**: Points, achievements, and voucher redemption

The design features a dark teal color scheme with green accents for environmental impact.
